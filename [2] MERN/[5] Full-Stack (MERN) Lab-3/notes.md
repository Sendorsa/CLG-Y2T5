## Course & Assessment Structure

### Learning Approach
1. **Each lecture** introduces concepts → problem statements are derived from those concepts
2. Students complete the problems from the previous lecture before the next class
3. New topics build on prior sessions progressively

### Project-Based Assessment (3-Step Projects)
| Phase | Description |
|-------|-------------|
| **Lab Projects** | Hands-on work throughout each session/lecture |
| **Safety Project** | Ongoing mid-course project |
| **End-of-Course Project** | Final submission at course conclusion |

### Expectations & Workflow
- Complete problems after every lecture/session
- At minimum, attempt the demo/task shown during class
- Lab projects continue across sessions — don't rely on passive learning (\"make up life form when you start\")

- New topics/techniques introduced in upcoming lectures
